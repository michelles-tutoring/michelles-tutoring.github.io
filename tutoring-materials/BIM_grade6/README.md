# Big Ideas Math — Grade 6

Tutoring materials based on the Big Ideas Math Grade 6 curriculum.

## File organization

- Put each presentation in its chapter folder.
- Name files `Section_X.X_Topic.pptx`.
- Add worksheets or tutor notes beside the matching presentation.
